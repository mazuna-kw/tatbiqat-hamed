# تطبيقات حامد — الحاسبة

مشروع Android تجريبي باللغة العربية باسم «الحاسبة». يتضمن العمليات الأساسية والأقواس والنسب المئوية والجذر التربيعي وذاكرة MC/MR/M+/M- وسجلًا محليًا لآخر 100 عملية.

تظهر عبارة «برمجة حامد الدهاش» داخل التطبيق.

## بناء APK
1. افتح تبويب Actions في المستودع.
2. اختر Build Android APK ثم Run workflow، أو انتظر بدء البناء بعد رفع الملفات.
3. افتح تشغيل البناء الناجح ونزّل artifact باسم alhasiba-debug-apk.
4. فك ضغط الملف لتحصل على app-debug.apk وثبّته على جهاز Android.

هذا إصدار Debug للتجربة وليس إصدارًا موقّعًا للنشر على Google Play.
