# ملك الأرقام — 2048 المطوّرة

نسخة Android أصلية باستخدام Kotlin وJetpack Compose، بواجهة عربية واتجاه RTL.

## الميزات في هذه النسخة الأولية
- لعبة 2048 تعمل محليًا دون إنترنت.
- أحجام لوحات 3×3 و4×4 و5×5.
- حفظ أفضل نتيجة واللعبة الحالية على الجهاز.
- تراجع عن الحركة السابقة.
- ثيم داكن/فاتح، ألوان بلاطات متدرجة، واهتزاز اختياري.
- تصميم بنفسجي/أزرق مستوحى من التصميم المعتمد.
- لا إعلانات ولا تحليلات ولا أذونات شبكة.

## البناء
من جذر المستودع:
```bash
./gradlew -p games/malik-al-arqam :app:assembleDebug
```
APK الناتج:
`games/malik-al-arqam/app/build/outputs/apk/debug/app-debug.apk`

يمكن أيضًا تشغيل GitHub Actions يدويًا من تبويب Actions واختيار **Build ملك الأرقام APK**.
هذه نسخة بداية تنفيذية؛ يجب اختبارها على جهاز فعلي قبل وصفها بأنها إصدار نهائي.
